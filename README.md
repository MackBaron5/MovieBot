# 🎬 Movie Selection Telegram Bot

Телеграм-бот на Python, который помогает пользователям искать информацию о фильмах и получать персональные рекомендации на основе их предпочтений.

## 🛠 Технологический стек
* **Язык программирования:** Python 3.x
* **Библиотека для бота:** pyTelegramBotAPI (telebot)
* **Работа с сетью:** Requests (интеграция с внешним API Кинопоиска)
* **Хранение данных:** База данных пользователей на основе формата JSON

## 🌟 Основной функционал
* **Поиск фильмов:** Пользователь отправляет название фильма, бот делает запрос к API Кинопоиска и возвращает подробную карточку (год, жанр, рейтинг, описание, страна).
* **Система предпочтений:** Пошаговый опрос пользователя для сохранения его любимого жанра и фильмов с использованием механизма состояний (State Machine).
* **Персональные рекомендации:** Выдача списка подходящих фильмов на основе сохраненных предпочтений.

## 🚀 Как запустить проект локально

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Установите необходимые зависимости:
   ```bash
   pip install pyTelegramBotAPI requests
   ```
3. Запустите бота:
   ```bash
   python main.py
   ```
